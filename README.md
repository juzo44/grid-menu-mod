# GRID Interface

Кастомное главное меню для клиента GRID. Заменяет стандартный титульный экран Minecraft на меню с фоном проекта, кнопками подключения к серверу и переходом в одиночный мир.

## Требования

- Minecraft 1.21.1
- NeoForge 21.1.244

## Установка

Положите собранный `gridmenu-1.0.0.jar` в папку `mods` клиента. После запуска меню заменится автоматически.

## Сборка

```powershell
gradlew build
```

Собранный jar появится в `build/libs/`.

## Возможности

- Фон и эмблема GRID, затемнение нижней части экрана
- Кнопка подключения к основному серверу
- Одиночный мир, настройки, выход
- Экран «О сервере» с копированием IP и ссылками на соцсети
- Пинг сервера: онлайн/оффлайн, количество игроков
- Поддержка геймпада (MidnightControls)

## Конфигурация

Адрес сервера задаётся константой `MAIN_IP` в `GridScreen.java` (по умолчанию `grid-server.ru`). Ссылки на соцсети — константы `TG_URL`, `DC_URL`, `WEB_URL`.

## Структура

- `GridMenu` / `GridMenuClient` — точка входа, подмена титульного экрана
- `GridScreen` — главное меню и отрисовка кнопок
- `ServerInfoScreen` — экран «О сервере»
- `ServerStatusManager` — периодический пинг сервера
